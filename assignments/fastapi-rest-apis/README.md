# 📘 Assignment: Building REST APIs with FastAPI

## 🎯 Objective

Learn how to build RESTful APIs using the FastAPI framework in Python. Students will create endpoints, handle requests, and return responses, gaining practical experience with modern web development.

## 📝 Tasks

### 🛠️ Create a Basic FastAPI Application

#### Description
Set up a FastAPI project and implement a simple API with at least one endpoint that returns a JSON response.

#### Requirements
Completed program should:

- Initialize a FastAPI app
- Create a root endpoint ("/") that returns a welcome message in JSON
- Run the server locally and test the endpoint


### 🛠️ Implement CRUD Operations

#### Description
Expand the FastAPI app to include endpoints for Create, Read, Update, and Delete operations on a resource (e.g., items, users).

#### Requirements
Completed program should:

- Define a resource model using Pydantic
- Implement endpoints for POST (create), GET (read), PUT (update), and DELETE (delete)
- Store resource data in a Python list or dictionary
- Return appropriate status codes and messages for each operation
