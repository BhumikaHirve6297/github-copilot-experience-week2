# 📘 Assignment: Statistics with Python

## 🎯 Objective

Learn to perform data analysis and statistical calculations using Python libraries such as pandas and numpy. Students will practice loading datasets, computing summary statistics, and applying statistical methods.

## 📝 Tasks

### 🛠️ Analyze a Dataset with Pandas

#### Description
Write a Python program to load a CSV dataset using pandas and compute basic summary statistics (mean, median, mode, standard deviation).

#### Requirements
Completed program should:

- Load a CSV file into a pandas DataFrame
- Calculate and display mean, median, mode, and standard deviation for numerical columns
- Handle missing values appropriately


### 🛠️ Statistical Calculations with Numpy

#### Description
Use numpy to perform statistical calculations on arrays, such as correlation, variance, and percentiles.

#### Requirements
Completed program should:

- Create numpy arrays from sample data
- Calculate correlation, variance, and percentiles
- Display results clearly and interpret findings
