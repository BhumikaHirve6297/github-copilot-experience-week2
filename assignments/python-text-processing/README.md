# 📘 Assignment: Python Text Processing

## 🎯 Objective

Learn to work with strings, file input/output, and text manipulation in Python. Students will practice reading and writing files, processing text, and applying string methods to solve real-world problems.

## 📝 Tasks

### 🛠️ Read and Process a Text File

#### Description
Write a Python program that reads a text file and processes its contents to count the number of lines, words, and characters.

#### Requirements
Completed program should:

- Open and read a text file
- Count and display the number of lines, words, and characters
- Handle file not found errors gracefully


### 🛠️ String Manipulation Functions

#### Description
Create functions to perform common string manipulations, such as removing punctuation, converting to lowercase, and finding unique words.

#### Requirements
Completed program should:

- Remove punctuation from a string
- Convert text to lowercase
- Extract and display unique words from the text
