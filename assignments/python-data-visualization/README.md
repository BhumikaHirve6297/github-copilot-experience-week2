# 📘 Assignment: Python Data Visualization

## 🎯 Objective

Learn to create charts and graphs using Python libraries such as matplotlib or plotly. Students will visualize data, customize plots, and interpret graphical representations.

## 📝 Tasks

### 🛠️ Create Basic Charts with Matplotlib

#### Description
Write a Python program to generate a bar chart and a line chart using matplotlib, based on sample data.

#### Requirements
Completed program should:

- Import and use matplotlib
- Create a bar chart for categorical data
- Create a line chart for numerical data
- Customize chart titles, axis labels, and colors


### 🛠️ Interactive Visualization with Plotly

#### Description
Use plotly to create an interactive scatter plot and pie chart from sample data.

#### Requirements
Completed program should:

- Import and use plotly
- Generate a scatter plot with interactive features
- Create a pie chart for proportions
- Add hover tooltips and customize appearance
